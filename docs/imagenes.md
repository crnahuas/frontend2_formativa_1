# Imágenes del sitio

## Portada generada

Método: herramienta integrada `image_gen`, sin CLI ni clave API del usuario. La imagen se creó para esta composición y se guardó en el proyecto como `public/images/portada-abasto.jpg`. Se utiliza una copia JPEG optimizada para la web. El original se conserva en la carpeta de imágenes generadas de Codex.

Prompt final:

> Use case: ads-marketing. Asset type: photographic background for a supermarket website hero banner. Generate one ultra-wide horizontal photograph, aspect ratio about 2.5:1. Scene: a seamless soft pale sage green studio wall and tabletop, fresh market groceries carefully arranged only in the right 55 percent of the frame. One slightly crumpled unbranded kraft paper grocery bag full of leafy green lettuce and a long baguette, bright tomatoes on the vine, whole lemons, zucchini, a pear and a few carrots at the base. Real natural produce with imperfections, warm morning side light and realistic gentle shadows cast to the right. Restrained commercial food photography, refined and inviting, no people. Crucial composition: leftmost 45 percent is completely empty uniform pale sage negative space for HTML typography; no objects or shadows crossing the left text area. Main composition fills right half with clear shapes, foreground groceries sit on tabletop, not floating. Camera at table level, slight downward angle, premium food photography with a clean editorial e-commerce feel. No printed text, logos, lettering, borders, graphic icons, cards or watermarks. Photographic image asset only, not a screenshot or website mockup.

## Referencia de diseño

[Eren, ThemesIndustry](https://themesindustry.com/html/eren/?storefront=envato-elements) se utiliza como referencia de composición. La implementación, el contenido y la fotografía de portada se adaptaron al supermercado Abasto. No se incorporaron los carritos, cuentas, pagos ni las demás funciones de comercio electrónico del ejemplo.
